# 社会プリント

小学1・2年の「さきどり社会」から、小学3〜6年の社会、中学の地理・歴史・公民まで、単元ごとの練習プリントを作る 1 ファイルの Web アプリです。
「算数プリント」(Math-worksheet-generator)・「理科プリント」(Science-worksheet-generator)と同じしくみ・同じ見た目で作っています。

- 公開ページ(予定): https://iamochiai-collab.github.io/Social-worksheet-generator/
- 作った人: 落合聡一

## できること

- **学年**: 小1・小2(さきどり社会)、小3〜小6(社会)、中学 地理・中学 歴史・中学 公民
- **特別支援学校(知的障害)の段階**: 小学部1〜3段階(生活)・中学部1・2段階(社会)・高等部1・2段階(社会)。学習指導要領の段階と内容(ア 社会参加ときまり、イ 公共施設と制度、ウ 地域の安全、エ 産業と生活、オ 我が国の地理や歴史、カ 外国の様子)にそって、学年べつの単元をならべなおしています
- **種類**
  - 基本問題 … 一問一答・（　）にことばを入れる・ア〜エからえらぶ・ならべかえ・〔ことば〕からえらぶ穴うめ・○×・（多く・少なく）の正しいほうを○でかこむ
  - 地図・資料 … 日本の白地図(都道府県・7地方)、世界地図(大陸・海洋・州・国)、地図記号、8方位、町の地図、雨温図、ぼうグラフ・折れ線グラフ、年表、三権分立の図、需要と供給の図、人口ピラミッド、等高線、水のゆくえ・119番のしくみの図
  - 一問一答 … 都道府県庁所在地(47都道府県)、何地方、地図記号、方位、人物、時代、時差の計算、縮尺の計算 など
  - 練習プリント … 1つの単元を、図 → 〔ことば〕の穴うめ → ○× → えらぶ → 一問一答 → 記述 の順に1〜2まいにまとめたもの
  - 単元まとめテスト … 100点満点
- **1・2年 さきどり社会**(ちびむすドリル「さきどり社会」の形にならいました): 絵を見て□に○×、ことばカードからえらんで図に書く(水のゆくえ)、ねふだを読む(産地)、キャラクターのヒントで都道府県をあてる
- **難易度** ★1〜3、**小単元** だけのプリント、**答えのページ**(プリントにオレンジで書きこむ形)、**ふりがな**・**習っていない漢字はひらがなに**、**まとめて作る**(印刷・PDF・JPG)

- **小学4年**(8単元):都道府県と地方、わたしたちの県の様子、水はどこから、ごみのしょりと利用、自然災害からくらしを守る、きょう土の伝統・文化、地いきの発展につくした人々、県内の特色ある地いき
- **小学5年**(11単元):世界の中の国土、国土の地形の特色、国土の気候の特色、特色ある地いきのくらし、米づくり、水産業、これからの食料生産、自動車をつくる工業、工業生産と貿易・運輸、情報産業とくらし、生活と環境
- **小学6年**(16単元):日本国憲法、国の政治のしくみ、くらしと政治、縄文〜古墳、飛鳥・奈良、平安、鎌倉、室町、戦国〜天下統一、江戸幕府、町人の文化と学問、明治の国づくり、世界に歩み出した日本、戦争と人々のくらし、戦後の日本、日本とつながりの深い国々・世界の未来

## フォルダ

- `content/*.js` … 問題のもと(ふつうの日本語で書く)。ここを直す
  - `r0lib.js` … 共通の道具 `RK`(理科プリントのものに、社会用の「○でかこむ」問題 `@…［正*・誤］` と一問一答 `RK.quiz` を足したもの)
  - `s0lib2.js` … 社会の図の道具 `SD`(地図記号・方位・日本地図・世界地図・雨温図・グラフ・三権分立など)
  - `s1saki.js`(小1・2)、`s3`〜`s6`(小3〜6)、`sct`(地理)、`srk`(歴史)、`skm`(公民)、`szstage`(特別支援の段階)
- `tools/shakai/makemap.js` … 地図のデータ(jpn-atlas・world-atlas)から `src/generators/s00map/part1.js` を作る
- `tools/rika/annotate.js` … content に ふりがな `{漢字|かな}` をつけて `src/generators/<名前>/part1.js` に書き出す。読みのまちがいは `tools/rika/yomi.txt` で直す
- `src/template.html` … アプリ本体(理科プリントのものを `tools/shakai/patch_template.py` で社会用にしたもの)
- `tools/build.py` … 1 ファイルにまとめて `docs/index.html`(公開用)と `build/test.html`(検査用)を作る

## 作りなおしと検査

```sh
npm install                          # はじめの1回(ふりがな用の kuromoji、地図のデータ、playwright)
node tools/shakai/makemap.js         # 地図のデータ(地図を変えたときだけ)
node tools/rika/annotate.js          # content → src/generators(ふりがなつけ)
python3 tools/build.py               # docs/index.html を作る
node tools/rika/check.js build/test.html 150              # 答え・図の検査
node tools/test/layout.js docs/index.html 結果.json 3,4   # はみ出し・番号のずれ(学年をしぼれる)
node tools/test/firstopen.js docs/index.html
node tools/rika/render.js build/test.html e4-01 figure normal 2 1 out/a-   # 画像にして目で見る
```
